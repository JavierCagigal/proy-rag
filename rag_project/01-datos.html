1. Datos

Un RAG solo sabe lo que hay en sus datos. Esta página explica de dónde salen, cómo se descargan y cómo se limpian. Todo lo hace un único script, src/pipeline.py, sin ningún paso manual: si mañana sale el reglamento de 2027, se cambia la URL, se vuelve a ejecutar y el asistente queda actualizado sin reentrenar nada.

Las fuentes

Elegimos fuentes con respuestas concretas (cifras), actuales (cambian cada año) y de nicho (poco presentes en internet), porque es ahí donde un LLM se inventa las cosas y donde un RAG marca la diferencia.

Mezclamos PDF y API, como pide la fase A. Los PDF son documentos públicos oficiales: se descargan en cada ejecución y no se suben al repositorio.

Descargar los PDF

def descargar_pdf(pdf):
    """Guarda el PDF en data/raw/ y devuelve la ruta. Si ya está, no lo baja otra vez."""
    ruta = RAW / (pdf["nombre"] + ".pdf")
    if ruta.exists():
        return ruta
    respuesta = requests.get(pdf["url"], headers=CABECERAS, timeout=60)
    respuesta.raise_for_status()
    if not respuesta.content.startswith(b"%PDF"):
        raise ValueError(f"{pdf['url']} no ha devuelto un PDF")
    ruta.write_bytes(respuesta.content)
    return ruta

Dos detalles. Si el PDF ya está en data/raw/, no se vuelve a bajar. Y la web de la WADA no sirve el archivo si la petición no parece de un navegador, por eso se envía una cabecera User-Agent.

Cada página se extrae por separado con pypdf, para poder citar el número de página en las respuestas.

Limpiar el texto

El texto de un PDF trae ruido que confunde a la búsqueda. Lo peor eran las páginas del índice: una línea como “5.5. IR O NO A RUEDA / DRAFTING ……… 47” se parece mucho a una pregunta sobre drafting, pero no contiene la respuesta.

def es_ruido(linea, repetidas):
    """Cabecera/pie repetido, línea de índice ("5.5. DRAFTING ....... 47") o número de página suelto ("35/212")."""
    linea = linea.strip()
    return (linea in repetidas
            or re.search(r"\.{5,}", linea) is not None
            or re.fullmatch(r"\d+(\s*/\s*\d+)?", linea) is not None)
def limpiar(texto, repetidas=frozenset()):
    """Quita el ruido, une palabras partidas con guion y normaliza espacios."""
    lineas = [l for l in texto.splitlines() if not es_ruido(l, repetidas)]
    texto = "\n".join(lineas)
    texto = re.sub(r"(\w)-\n(\w)", r"\1\2", texto)   # "competi-\nción" -> "competición"
    texto = re.sub(r"[ \t]+", " ", texto)             # varios espacios -> uno
    texto = re.sub(r"\n{3,}", "\n\n", texto)          # deja como mucho una línea en blanco
    return texto.strip()

Las cabeceras y pies se detectan solos: son las líneas que se repiten en más de la mitad de las páginas de un documento.

Los medicamentos de CIMA

La pregunta “¿me da positivo el Ventolin?” no se puede contestar solo con la lista de la WADA, que habla de salbutamol y nunca dice “Ventolin”. CIMA traduce el nombre comercial al principio activo y dice la vía de administración, que cambia la respuesta: el salbutamol inhalado está permitido con límites y en jarabe no.

No bajamos los más de 20.000 medicamentos de España: solo los de 24 principios activos que importan en el deporte.

def descargar_cima(principio_activo):
    """Devuelve la lista de medicamentos (dicts del JSON) que llevan ese principio activo."""
    ruta = RAW / "cima" / f"{principio_activo}.json"
    if ruta.exists():
        return json.loads(ruta.read_text(encoding="utf-8"))
    medicamentos, pagina = [], 1
    while True:  # la API va por páginas (totalFilas, pagina, tamanioPagina)
        respuesta = requests.get(CIMA_URL, params={"practiv1": principio_activo, "pagina": pagina},
                                 headers=CABECERAS, timeout=60)
        respuesta.raise_for_status()
        datos = respuesta.json()
        medicamentos += datos.get("resultados", [])
        if pagina * datos["tamanioPagina"] >= datos["totalFilas"]:
            break
        pagina += 1
    ruta.parent.mkdir(parents=True, exist_ok=True)
    ruta.write_text(json.dumps(medicamentos, ensure_ascii=False), encoding="utf-8")
    return medicamentos

La API devuelve los resultados por páginas, así que el bucle pide la siguiente mientras queden. Después nos quedamos solo con los medicamentos comercializados y de marca: los genéricos ya llevan el principio activo en el nombre (“PARACETAMOL CINFA”), y las marcas (“Frenadol”, “Adolonta”) son justo lo que un LLM no conoce.

Cada medicamento se convierte en una frase corta:

def texto_medicamento(medicamento, principio_activo):
    """Convierte un medicamento en una frase para el corpus."""
    vias = ", ".join(v["nombre"].lower() for v in medicamento.get("viasAdministracion", []))
    forma = medicamento.get("formaFarmaceutica", {}).get("nombre", "").lower()
    receta = "Con receta" if medicamento.get("receta") else "Sin receta"
    return (f"{medicamento['nombre']}. Medicamento español. Principio activo: {principio_activo}. "
            f"Forma: {forma}. Vía de administración: {vias}. {receta}.")
